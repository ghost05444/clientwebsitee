# Products still needing a photograph

Generated by `npm run audit:images` from the built catalogue.

**40 of 849 products** have no photograph. They render the site's own "image not available" placeholder — quiet and
consistent with the design, not a broken image.

Of these, 35 previously displayed the source catalogue's grey
"No image available" graphic. That artwork is now stripped in the data
pipeline (see `PLACEHOLDER_HASHES` in `scripts/build-data.mjs`), so those
products show the site's placeholder instead of someone else's.

## Adding a photograph

Save it as `public/media/<year>/<month>/<Name>-400.webp` and `-900.webp`
(square, white background matches the rest of the catalogue), add the path
to the product in `scripts/raw/products.json`, then run `npm run data`.
Re-run this audit and the product drops off the list.
